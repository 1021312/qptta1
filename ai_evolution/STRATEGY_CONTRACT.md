# AI Strategy Contract

AI코딩 연구실에서 생성되는 모든 매매법은 아래 공통 인터페이스를 따릅니다.

## 공통 하위탭

모든 전략은 자동으로 다음 5개 하위탭을 가집니다.

1. 종목추천
   - 현재가
   - 추천매수가 하단/상단
   - 손절가
   - 1차/2차 매도가
   - 예상 보유기간
2. 3년백테스트
   - 10,000,000원 총자본 기준
   - 동시 최대 5종목 균등배분
   - 거래비용/슬리피지 반영
   - 체크포인트 이어진행
3. 성과검증
   - D+1/3/5/10/20 실제 성과
4. 모의매매
   - 전략별 독립 모의계좌
5. 학습AI
   - 챔피언/도전자
   - 변형전략 자동생성
   - 미사용구간 검증

## 승격 규칙

새 전략은 메인 실전주문 코드를 직접 수정하거나 덮어쓰지 않습니다.

전략 생성 -> 3년 백테스트 -> 마지막 20% 미사용구간 -> 실제 추천성과 -> 모의매매 -> 챔피언 후보 순으로 이동합니다.

원격 GitHub 코드는 exec/eval/import 하지 않습니다. GitHub는 아이디어, 메타데이터, 테스트 기록, 후보 전략 버전관리 용도로 사용합니다.
